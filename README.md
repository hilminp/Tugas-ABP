# 🧠 Curhatin

Platform digital berbasis web dan mobile yang menyediakan ruang aman bagi pengguna untuk berbagi cerita, mengekspresikan perasaan, serta terhubung dengan psikolog secara mudah dan nyaman.

---

## 📌 Tentang Project

Curhatin dikembangkan untuk membantu pengguna mendapatkan tempat yang aman untuk mencurahkan perasaan, berbagi pengalaman hidup, dan memperoleh dukungan psikologis melalui platform digital.

Project ini dikembangkan sebagai tugas besar akademik menggunakan arsitektur client-server dengan teknologi modern.

---

## 🚀 Teknologi yang Digunakan

## ⚙️ Instalasi

### Backend Laravel

```bash
cd backend

composer install

cp .env.example .env

php artisan key:generate

php artisan migrate

php artisan serve
```

### Frontend React

```bash
cd frontend

npm install

npm run dev
```

### Mobile Flutter

```bash
cd mobile

flutter pub get

flutter run
```
